## What are Claude Skills?

**Skills** are reusable system prompts and instructions that shape how AI coding assistants behave on specific tasks. Instead of pasting a long prompt every time, you ship a skill (a markdown file, sometimes with attached scripts or assets) and your AI uses it on demand.

There are several closely-related flavors all indexed in this list:

- **Claude Code Skills** — Anthropic-anchored, typically lives in `.claude/skills/`, invoked by [Claude Code](https://mcp.directory/clients/claude-code)
- **Anthropic Agent Skills** — Anthropic's broader Agent Skills framework
- **Cursor Rules** — [Cursor](https://mcp.directory/clients/cursor)'s equivalent, lives in `.cursor/rules/` as `.mdc` files

## FAQ

**What is a Claude Code Skill?**
A reusable system prompt + instructions that Claude Code can invoke for specific tasks. Lives in `.claude/skills/SKILL_NAME/SKILL.md` in your repo. [Browse all Claude Code skills →](https://mcp.directory/skills)

**How do I install a skill?**
Drop the skill folder into your project's `.claude/skills/` directory (or the equivalent for your client). Claude Code auto-discovers them. Detailed setup at [mcp.directory/clients/claude-code](https://mcp.directory/clients/claude-code).

**What's the difference between a skill and an MCP server?**
A **skill** is a prompt/instruction set that shapes how the AI thinks. An **MCP server** exposes external tools the AI can call (file access, API calls, etc.). They complement each other. See [awesome-mcp-servers](https://github.com/devanshug2307/awesome-mcp-servers) for the server side.

**What's the difference between Claude Code Skills, Agent Skills, and Cursor Rules?**
Same idea, different surface: Claude Code Skills are Anthropic's CLI-anchored format, Agent Skills are the broader Anthropic framework, Cursor Rules are Cursor's equivalent. Many skills work on multiple clients with minor adaptation.

**Are skills safe to install?**
Skills are markdown — they don't execute code by themselves, but they instruct your AI to do things. Read the SKILL.md before installing. For skills that ship scripts/binaries, audit those separately.

**Can I write my own skill?**
Yes. The format is simple: a folder with a `SKILL.md` describing what the skill does, when to use it, and any references. Submit at [mcp.directory/submit-skill](https://mcp.directory/submit-skill).

**How does mcp.directory rank skills?**
By installation count and view count from the directory itself.

**Is there a public API?**
Yes — [`/api/v1/skills`](https://mcp.directory/api/v1/skills). Open, no auth required, JSON.
