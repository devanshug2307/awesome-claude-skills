# Contributing

This repository is **auto-generated** from [mcp.directory](https://mcp.directory). The README, category sections, and alphabetical lists are produced from a single source of truth and refreshed weekly.

## Adding your skill

1. Submit at https://mcp.directory/submit-skill
2. After review (typically <72 hours), your skill will appear here on the next refresh.

We accept:
- Claude Code Skills (`.claude/skills/`)
- Anthropic Agent Skills
- Cursor Rules (`.cursor/rules/`)
- Other system prompts/instructions for AI coding assistants

## Reporting data errors

Open an [issue](https://github.com/devanshug2307/awesome-claude-skills/issues/new) with:

- The skill slug (e.g., `mcp.directory/skills/your-skill`)
- What's wrong (description outdated, link broken, miscategorized, attribution wrong, etc.)

Corrections are applied upstream at mcp.directory and propagate here on the next regeneration.

## Pull requests

Direct PRs editing the markdown will be closed — changes are overwritten on every refresh. Submit upstream at [mcp.directory/submit-skill](https://mcp.directory/submit-skill) instead.
